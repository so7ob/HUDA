# اختبارات E2E — المسارات الحرجة (Issue #10)

> «سكربت واحد يجري المسارات الحرجة خضراء على كل PR» — هذه هي الوثيقة المرجعية للتنفيذ.

## التشغيل

```bash
bun run test:e2e          # تشغيل كامل (خادم مستقل + قاعدة معزولة + متصفح)
bun run test:e2e:headed   # مع رؤية المتصفح
npx playwright show-report # تقرير HTML (في CI فقط) — أو show-trace للآثار
```

- المشغّل: Playwright 1.57 (chromium 1200) عبر Node — **لا** عبر bun runtime.
- لا يشترط خادمًا قائمًا: الـ config يقلع خادم Next dev مستقلًا على المنفذ **3105** وينتظر `/api/health`.
- للفحص السريع أثناء التطوير: `npx playwright test tests/e2e/reading.spec.ts` (سطر واحد).

## العزل الكامل — لماذا النتائج حتمية

| المورد | الآلية |
|---|---|
| قاعدة البيانات | `db/e2e.db` تُبنى من نسخة `db/custom.db` في `global-setup` قبل كل تشغيل (114 سورة، 6236 آية، مقرئون، كتب) |
| بيانات الاستخدام | تصفير `Favorite/Bookmark/LastReading/LastBookRead/DownloadedRecitation/AdminSession` في البذرة (`tests/e2e/seed-e2e.ts`) |
| حساب الإدارة | كلمة مرور المدير `admin` تُعاد ضبطها إلى قيمة E2E معلومة بتجزئة scrypt مطابقة لـ `hashPassword` |
| الشبكة الخارجية | تلاوة CDN تُعترض بـ `page.route` وتُغذّى WAV مُصنَّع برمجيًا — صفر طلبات خارجية |
| الخادم | عملية Next dev مستقلة (منفذ 3105) مع `DATABASE_URL=file:../db/e2e.db` — لا تلمس قاعدة المعاينة |
| حدّ المحاولات | في الذاكرة داخل خادم جديد لكل تشغيل — يبدأ صفرًا |

المسار النسبي `file:../db/e2e.db` يُحلّ نسبةً إلى مجلد `prisma/` (سلوك Prisma الموثق) — أي أن الملف الفعلي هو `db/e2e.db` بجذر المشروع.

| الملف | المسار |

| `search.spec.ts` | بحث محلي بنتائج مجمعة ← حالة «لا توجد نتائج» ← فتح نتيجة يفتح القارئ |

| `admin-auth.spec.ts` | دخول صحيح يفتح اللوحة ← رفض كلمة مرور خاطئة ← قفل حدّ المحاولات (5 فاشلة/15 دقيقة) |

## دروس حاسمة (لا تُكرر أخطاءها)

1. **أسماء السور بالرسم العثماني** («ٱلْفَاتِحَةِ») — لا تطابق نصًّا عاديًّا («الفاتحة»)؛ استخدم ترتيب الفهرس الثابت أو بنية الأدوار.
2. **درج إجراءات الآية (vaul) يبقى مفتوحًا بعد الإضافة** ويضع `aria-hidden` على كل ما خلفه — أغلقه بـ Escape قبل أي تفاعل مع القارئ وإلا «اختفى» من شجرة الوصول.
3. **زر التلاوة العائم يختفي عند ظهور المشغّل المصغّر** (`player.visible`) — تأكيد التشغيل عبر زر «إيقاف» في المشغّل المصغّر أو `window.__hudaAudio` (تطوير فقط).
4. **نقرات Playwright حقيقية** تمنح إذن autoplay — لا حاجة لأي تجاوز لسياسات المتصفح.
5. **bun test لا يلتقط مواصفات Playwright**: `bunfig.toml` يقيّد `[test].root` إلى `tests/unit` — إبقاء القناتين منفصلتين.
6. العدّاد في شاشة المفضلة بأرقام عربية («(١)») — التأكيدات بنمط `toContainText("(١)")`.

## CI

`.github/workflows/ci.yml` يتضمن job `e2e-critical-paths`: bun install → prisma generate → `npx playwright install chromium --with-deps` → `bun run test:e2e` مع رفع تقرير/آثار عند الفشل (احتفاظ 7 أيام). إنه إلزامي على كل PR إلى develop مثل بقية البوابات.
