# دليل إدارة المحتوى — نور الهدى

لوحة الإدارة تُفتح من: **الإعدادات ← لوحة الإدارة** وتطلب تسجيل دخول. كل الإضافات تتم من الواجهة دون تعديل شيفرة.

## 0) المصادقة والحماية
- كل مسارات `/api/admin/*` محمية بجلسة كوكي `httpOnly` صالحة ٧ أيام (تُبطل عند الخروج أو انتهاء المدة).
- الحساب الافتراضي عند أول تشغيل: **admin / admin123** (المالك `owner`) — كلمة المرور تُحفظ كتجزئة scrypt مع ملح عشوائي، ويُطلب تغييرها فور أول دخول من قائمة الحساب ← «تغيير كلمة المرور».
- تسجيل الخروج من قائمة الحساب (أيقونة المفتاح في الترويسة) — يُسجّل الدخول والخروج في سجل التدقيق.
- كلمات المرور لا تُخزن ولا تُرسل إلا عبر مسار تسجيل الدخول، ولا يوجد أي وصول للإدارة بلا جلسة (401).
- تنبيه: عند النشر خلف Nginx/HTTPS اجعل كوكي الجلسة `secure: true` في `src/lib/admin-auth.ts`.

## 0.1) تبويبات اللوحة الثمانية
نظرة عامة (سير النشر المرئي + إجراءات سريعة) / الكتب (فلتر حالة + تمييز بنجمة) / الأقسام (إضافة وتعديل وحذف الفارغ) / المواضيع (إنشاء + إدارة الآيات) / المقرئون (إضافة وتعديل وافتراضي وإيقاف) / الحزم (تجديد ورفع إصدار) / البيانات (نسخ واستعادة وتصدير وصيانة) / السجل (فلاتر وبحث).

## 1) الفلسفة
- **محرك محتوى مرن**: الأقسام ليست مبرمجة بأسماء ثابتة — إنشاء قسم جديد يظهر فورًا في «المكتبة» و«مع الرسول والرسالة».
- **فصل المحتوى عن المحرك**: نفس القاعدة تخدم أي تطبيق آخر (تغيير هوية/أقسام دون لمس منطق العرض).

## 2) سير عمل النشر

```
مسودة ← مراجعة ← اعتماد ← نشر ← أرشفة
```

- لكل كتاب شارة حالة وزر «التقدم بالسير» يعرض الخطوة التالية باسمها.
- كل تغيير حالة يُسجَّل في **سجل التدقيق** (الفاعل، الإجراء، الكيان، التفاصيل، الوقت) — تبويب «السجل».
- الكتاب لا يظهر في التطبيق العام إلا بحالة **منشور**.
- الأرشيف يخفي الكتاب دون حذفه، ويمكن إعادته إلى «مسودة».

## 3) إدارة الكتب والفصول
1. **إضافة كتاب**: العنوان (إلزامي) + القسم + المؤلف + الوصف + نمط الغلاف (فيروزي/رملي/ليلي) + المصدر + الحقوق.
2. **الفصول**: من زر «الفصول» — إضافة/تعديل/حذف. المحتوى يدعم:
   - العربية المشكلة كاملة.
   - `**نص عريض**` للعناوين الفرعية والحواشي المميزة.
   - كل فصل صفحة مستقلة في قارئ الكتب مع فهرس تفاعلي.
3. **المصدر والحقوق**: احرص على تعبئة «المصدر» و«الحقوق» — تظهر في صفحة الكتاب وتبني ثقة المستخدم وتحمي الناشر.

## 4) الأقسام
- إنشاء قسم جديد: العنوان + الوصف + الأيقونة + اللون (فيروزي/رملي).
- **تعديل القسم**: أيقونة القلم — يغيّر العنوان/الوصف/الأيقونة/اللون فورًا في المكتبة.
- إخفاء قسم (إيقاف التفعيل) يخفيه من التطبيق دون حذف كتبه.
- **حذف قسم**: متاح للأقسام الفارغة من الكتب فقط (يُرفض الحذف مع رسالة توضيحية إن كان يحوي كتبًا).

## 5) المواضيع (الفهرس الموضوعي)
- **إنشاء موضوع جديد**: يُنشأ غير منشور — أضف آياته ثم فعّل النشر.
- تعديل الوصف، نشر/إخفاء الموضوع.
- **إدارة الآيات**: زر القائمة يفتح حوار الآيات — إضافة سورة+آية (بملاحظة اختيارية) وحذف بالمعرّف، مع عرض نص الآية المعتمد.
- إضافة آيات لموضوع: **تُرفض آليًا** أي إحالة غير موجودة في بيانات المصحف (تحقق مزدوج سورة+آية).
- ⚠️ **النص القرآني نفسه لا يُعدَّل من هنا** — استيراد النص عبر `scripts/seed.ts` الموثق فقط.

## 6) النسخ الاحتياطي
- **تصدير بيانات المستخدم** (مفضلة/علامات/أوراد/إعدادات): الإعدادات ← النسخ الاحتياطي.
- **نسخة كاملة إدارية** (تشمل الكتب والأقسام والمواضيع): زر «نسخة احتياطية كاملة».
- **الاستعادة**: ترفع ملف JSON — تستبدل بيانات الاستخدام فقط، ولا تمس المرجع القرآني.

## 7) حزم المحتوى
- شاشة «حزم المحتوى» تعرض الحزم (قرآن/تفسير/كتب/تلاوات) بحجمها وإصدارها وزر التحقق/التحديث.
- تحديث الحزمة لا يمس بيانات المستخدم أبدًا (فصل صريح بين المرجع والشخصي).

## 8) إدارة المقرئين
- **من اللوحة** (تبويب «المقرئون»): إضافة مقرئ جديد (معرّف + اسم + رواية + نمط + جودة + نمط رابط صوت + مصدر + حقوق)، تعديل، تفعيل/إيقاف، تعيين الافتراضي بنجمة، حذف غير الافتراضي.
- نمط الرابط يقبل العنصرين النائبين `{ayahId}` أو `{ayah}` — كلاهما يُستبدل بالرقم العالمي للآية (١–٦٢٣٦).
- الإيقاف يخفي المقرئ من قائمة القراء دون حذفه؛ الافتراضي لا يُوقف ولا يُحذف.
- من الإعدادات العامة: تعيين الافتراضي من واجهة القراء، والتنزيلات (حجم كل سورة + حذف).

## 9) قواعد ذهبية للمشرف
1. لا تنشر نصًا دينيًا بلا مصدر موثق مكتوب في حقل «المصدر».
2. راجع «السجل» دوريًا لاكتشاف أي تعديل غير مقصود.
3. جرّب الكتاب في وضع «مراجعة» على جهازك قبل «النشر».
4. خذ نسخة احتياطية قبل أي استعادة.
