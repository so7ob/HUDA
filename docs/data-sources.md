# مصادر البيانات والتراخيص — نور الهدى

> مبدأ غير قابل للتفاوض في هذا المشروع: **لا محتوى مختلقًا**. كل نص ديني معروض له مصدر موثق وترخيص معلن، والنصوص الأصلية لا تُعدَّل أبدًا (التطبيع يُطبَّق على فهرس البحث فقط).

## 1) النص القرآني

| البند | القيمة |
|---|---|
| النص | العثماني برواية **حفص عن عاصم** — تقسيم مدني (604 صفحات / 30 جزءًا / 240 حزبًا) |
| المصدر | مشروع **Tanzil** (نص موثق ومُدقَّق مجتمعيًا) — عبر `api.alquran.cloud/v1/quran/quran-uthmani` |
| الترخيص | Tanzil: نص مفتوح بشرط عدم التعديل — نعرضه كما هو دون أي تغيير رسم أو تشكيل |
| طريقة الاستيراد | `scripts/seed.ts` → تخزين في جدول `QuranAyah` مع أرقام (سورة/آية/صفحة/جزء/حزب/سجدة) |
| الحماية | جدول `QuranAyah` **لا تتوفر له أي واجهة تعديل إداري** — سير عمل الاستيراد منفصل وموثق |
| التحقق | تطابق عدد الآيات: 6236 ✓ — عدد السور: 114 ✓ — صفحات الفهرس 1–604 ✓ |

## 2) رسم المصحف المدني (وضع المصحف) — خطوط QCF المرخصة

> **جردة مستودع «هدى» (`github.com/so7ob/HUDA`) — ما استُخدم وما لم يُستخدم:**
>
> | ملف المستودع | المحتوى | القرار |
> |---|---|---|
> | `main_db@2.zip` | قاعدة بيانات SQLite (224 م.ب): رموز رسم المصحف، أسماء السور، جداول القرآن والصوت | ✅ **مُستخدَم** — استيراد موثق أدناه وفقًا لـ `scripts/import-huda.ts` |
> | `mushaf_.zip` (54 م.ب) | خطوط QCF الأصلية: `QCF_P001–P604.TTF` + `QCF_BSML.TTF` (605 ملفًا) | ✅ **مُستخدَم** — `public/fonts/qcf/`؛ تحقق تطابق بتّي (checksum) للملفات الـ 605 كاملة مع المستودع ✓ |
> | `assets.zip` (4.5 م.ب) | خطوط التطبيق (UthmanicHafs، AbdoLine، Newmalazim، ElMessiri ×4) + صور واجهة أندرويد | ✅ الخطوط **مُستخدَمة** (تطابق بتّي ✓) — الصور **لم تُنسخ** (انظر القسم 8) |
> | `res.zip` (448 ك.ب) | مجلد `res/` من APK الأندرويد: أيقونة المشغّل بشعار «هدى الله»، خلفيات nine-patch، تخطيطات XML مجمّعة | ⛔ **لم يُستخدَم عمدًا** — أصول هوية بصرية وواجهة خاصة بالتطبيق المرجعي (انظر القسم 8)، وصيغة أندرويد المجمّعة لا صلة لها بالويب |
>
> ملاحظة ترقيم مستخلصة من قاعدة «هدى»: جدول `quran_ayah` فيها يعدّ **البسملة آيةً مستقلة** (`ayah_number=0`) لكل سورة عدا الفاتحة والتوبة (6348 صفًا بدل 6236) — تُطبَّع الأرقام عند حدّ الـ API كما هو موثق أدناه.

| البند | القيمة |
|---|---|
| النظام | **خطوط صفحات المصحف المدني (QCF)** — مجمع الملك فهد لطباعة المصحف الشريف: خط مستقل لكل صفحة `QCF_P001.TTF … QCF_P604.TTF` + خط ترويسة البسملة `QCF_BSML.TTF` |
| المصدر | أصول تطبيق «هدى» المفتوح (`github.com/so7ob/HUDA` → `mushaf_.zip`) — الملفات الأصلية لمجمع الملك فهد دون تحوير، **متحقق منها بتّيًا** |
| الترخيص | خطوط مجمع الملك فهد لطباعة المصحف الشريف — إتاحة الاستخدام للقرآن الكريم وفق شروط المجمع (لا تُستخدم إلا لرسم المصحف) |
| بيانات الرموز | جدول `QuranGlyph` (88,246 صفًا) مستورد من قاعدة بيانات «هدى» (`db/sources/main_db.sqlite`) — نقطة يونيكود لكل كلمة/علامة مع رقم السطر (1–15) والآية والصفحة |
| طريقة العرض | يُحمَّل خط الصفحة عند الطلب (FontFace API + تخزين مسبق للصفحات المجاورة)؛ تُرسم الأسطر الخمسة عشر بالقياس والملاءمة؛ **النص الرسومي لا يُعدَّل إطلاقًا** — يُعرض كما استُورد |
| عناصر الصفحة | صناديق السور وسطور البسملة بخط الترويسة المرخص (الرموز `U+FB51–FB54`)؛ السطور القصيرة تُحاذى يمينًا كالمصحف |
| التحقق | صفحة 2 (بداية البقرة: صندوق + بسملة + 6 أسطر) ✓ — صفحة 77 (بداية النساء بسطر مدمج) ✓ — صفحة 106 (بداية المائدة وسط الصفحة) ✓ — صفحة 604 (3 سور) ✓ |
| تطبيع الترقيم | قاعدة «هدى» تعدّ **البسملة آيةً مستقلة** (`ayah_number=0`) لكل سورة عدا الفاتحة والتوبة (6348 صفًا بدل 6236)، لذا `ayah_id` فيها منزاح عن الترقيم العالمي القياسي بمقدار عدد البسملات السابقة (البقرة 2 = هدى 10، القياسي 9). تُطبَّع `aid` عند حدّ الـ API (`/api/quran/page/[p]/mushaf`) إلى الرقم العالمي القياسي بالربط مع `QuranAyah` على (السورة، رقم الآية) — بيانات المصدر المستوردة تبقى كما هي دون تعديل |
| الحماية | جدول `QuranGlyph` مرجعي فقط — لا واجهة تعديل له |

## 3) التفسير

| البند | القيمة |

## 4) التلاوات الصوتية

| البند | القيمة |

| التنزيل | في الويب: تسجيل التنزيل + ذاكرة المتصفح المؤقتة (قياس HEAD فعلًا مع تقدير معلن عند الفشل). في نسخة الجوال: تخزين ملفات كامل محليًا |

## 6) الفهرس الموضوعي

- 7 مواضيع (الإيمان، الأخلاق، العبادة، الأسرة، المعاملات، القصص القرآني، القيم والسلوك) بآيات مرجعية مشهورة **قابلة للمراجعة العلمية**.
- كل ربط يحمل حقل `note` لسبب الربط، ويُدار من لوحة الإدارة (نشر/إخفاء/إضافة — تُرفض آليًا الآيات غير الموجودة في المصحف).

## 8) الأصول البصرية

- **رموز وأشكال «هدى الله» (توجيه صريح من المالك، 2025)**: بناءً على تعليمات صاحب المشروع المباشرة («استخدم كل الرموز والأشكال الموجودة فيه») أُدجت الأصول المستخرجة من `res.zip` — مستودع HUDA المفتوح <https://github.com/so7ob/HUDA> — مع الإسناد الكامل للمصدر:
  - **الشعار** (`8O.png` ← `/huda/logo.png`): أيقونة التطبيق، favicon (32→512)، أيقونة Apple touch، شاشة «حول التطبيق»، ترويسة الرئيسية.
  - **نقش زخرفي داكن** (`pu.png` ← `/huda/pattern-dark.png`): طبقة نقش فائقة الترويسات الفيروزية وشاشة «حول» عبر أداة `.header-pattern`.
  - **رموز المشغّل** (تشغيل `zk` / إيقاف `YB` / السابق `1u` / التالي `HA` / إيقاف تام `FW`): أزرار المشغّل المصغّر ولوحة التلاوة.
  - **قطرات «الورد»** (`g-`, `5U`, `jW`, `EP`): فاصل بطاقات الأوراد وحالات الفراغ في البرنامج اليومي.
  - **أشكال عامة** (تحديد `tG`/`dY`، سهم فتح `kp`، هاتف `MD`، فيديو `OX1`، حلقات ومربعات وأسهم وفواصل): شاشة المقرئين، معرض «مكتبة الرموز والأشكال» في «حول التطبيق»، قسم الدعم.
  - **الفهرس الكامل**: `/huda/catalog.json` يوثّق **كل ملفات الحزمة** (331 ملفًا: أبعاد + تصنيف) بما فيها خلفيات 9-patch وتخطيطات XML غير القابلة للاستخدام الويبي مباشرة؛ والتفاصيل في `/huda/README.md`.
  - **تنبيه ترخيصي**: المستودع المصدري بلا ملف ترخيص صريح وقت التحميل؛ الأصول مستخدمة بوصفها أصول واجهة من مشروع منشور علنًا مع ذكر المصدر — للنشر التجاري يلزم التحقق من الرخصة مع مالكها.
- **الشعار الأصلي البديل**: زخارف SVG أصلية (`src/components/shared/logo.tsx`, `ornaments.tsx`) ما تزال مستخدمة في بطاقات المكتبة والسير — هوية موازية مستقلة.
- **الألوان**: لوحة tokens مركزية في `globals.css` (فيروزي `#329B9C` / داكن `#247E83` / خلفية `#F8FDFC` / قراءة `#EBFBFA` / كريمي `#E9EEE2` / نص `#283333`).

## 9) اختبارات سلامة النص (كيف تتحقق بنفسك)

```bash
# عدد الآيات الكلي
curl -s localhost:3000/api/quran/surahs | python3 -c "import json,sys; d=json.load(sys.stdin)['surahs']; print('سور:',len(d),'آيات:',sum(s['ayahCount'] for s in d))"
# → سور: 114 آيات: 6236

# أول آية من الفاتحة بالنص العثماني
curl -s localhost:3000/api/quran/surah/1 | python3 -c "import json,sys; print(json.load(sys.stdin)['ayahs'][0]['text'])"

# تفسير آية الكرسي (مصدر معلن)
curl -s localhost:3000/api/quran/tafsir/2/255 | python3 -c "import json,sys; d=json.load(sys.stdin); print(d['source']['name'], '—', d['text'][:60])"

# رموز رسم المصحف لصفحة (2): عدد الرموز والسطور
curl -s localhost:3000/api/quran/page/2/mushaf | python3 -c "
import json,sys; d=json.load(sys.stdin)
print('خانات:', len(d['slots']), '| رموز:', sum(len(s.get('items',[])) for s in d['slots']))"

# إعادة استيراد بيانات الرسم (إن لزم) — المصدر المحفوظ في db/sources/
# bun scripts/import-huda.ts
```

## 10) القيود المعلنة (شفافية كاملة)

1. **بيئة التسليم الحالية ويب**: لا يمكن بناء APK داخلها؛ خطة النقل الكاملة إلى Flutter/Android موثقة في `docs/flutter-port.md`.
2. **كتب التطبيق المرجعي المحمية**: لم تُدرَج (حقوق) — محرك المحتوى جاهز لإضافتها عند توفر ترخيص.
3. **تنزيل التلاوات في الويب**: إدارة بيانات + ذاكرة مؤقتة؛ التخزين الملفي الكامل خاصية نسخة الجوال.
4. **تذكيرات الخلفية**: في الويب تعمل أثناء فتح التطبيق؛ الخلفية الدائمة تحتاج التطبيق الأصلي.
